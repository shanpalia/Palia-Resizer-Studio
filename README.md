# Palia Resizer Studio — By PaliaAPK HUB

A responsive browser-based image utility with a white and mint visual identity.

## Current working features
- Custom image dimensions with optional aspect-ratio lock
- Preset output sizes for square, social post, story, HD, and Full HD
- Browser-local image loading and canvas export
- Crop using source-image X/Y/width/height fields
- Rotate and flip controls
- Export to JPEG, PNG, or WebP
- Quality slider and best-effort target file size for JPEG/WebP
- Responsive layout for desktop and mobile

## Privacy
The core editor processes selected images in the browser; it does not upload them to a server.

## Use
Open `index.html` locally, or enable GitHub Pages from **Settings → Pages** and select the `main` branch and root folder.

## Honest feature status
AI upscaling and PDF/video/audio conversion are not connected in this repository yet. No fake results, counters, or demo output are shown.
